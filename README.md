# Your People Now

Build NOW — Social App

Build a modern social networking app called NOW.

1. Product Identity

Brand: NOW

Core tagline:

See your people, right now.

NOW is a spontaneous social app centered around seeing what people are doing right now, rather than creating polished social media content.

The product should feel:

spontaneous

intimate

playful

minimal

slightly mysterious

addictive without feeling overwhelming

modern and premium

Do NOT make it feel like Instagram, TikTok, or Snapchat.

The closest visual references are BeReal's simplicity + Notion's clean product design, but NOW must have its own visual identity.

The main idea:

Friends → World → Events → Memories

Users initially open NOW to see their friends, but stay because they can discover the world and build a personal archive of their life.

2. VISUAL DESIGN

Create an extremely clean, minimal interface.

Design references

Take inspiration from:

BeReal — simplicity and spontaneity

Notion — typography, spacing, clean information hierarchy

Do NOT copy either product.

Color palette

Use a mostly monochrome interface:

Off-white / warm white background

Near-black text

Soft gray secondary text

Very subtle borders

Minimal use of color

Use one distinctive NOW accent color sparingly for:

active states

NOW DROP

important notifications

buttons

special events

The accent should feel energetic but sophisticated.

Avoid gradients.

Avoid excessive shadows.

Avoid glassmorphism.

Avoid colorful social-media-style UI.

Typography

Use a clean modern sans-serif.

Large, confident typography for:

NOW

countdowns

event titles

Small, subtle typography for:

timestamps

metadata

secondary information

Use generous whitespace.

Rounded corners should be subtle, not excessive.

3. BRANDING

The logo should simply be:

NOW

Use a minimal wordmark.

The word NOW should be recognizable without needing an icon.

App copy should use NOW naturally.

Examples:

Post a NOW.

Your NOW is ready.

See their NOW.

Missed your NOW.

Replay your NOWs.

What's happening NOW?

Use "NOW" as a product language system.

4. CORE APP STRUCTURE

Create these main navigation sections:

NOW

Friends' current moments.

WORLD

Random NOWs from around the world.

EVENTS

Community-wide moments and challenges.

MEMORIES

Personal archive of previous NOWs.

Also include:

Notifications

Profile

Settings

Keep navigation extremely simple.

Use a minimal bottom navigation bar on mobile.

5. HOME — FRIENDS NOW

The main screen should immediately show the user's friends' latest NOWs.

Each NOW is a visual card.

A NOW contains:

photo

optional front/back camera composition

username

approximate timestamp

reactions

optional location context

optional "Together" indicator

Do not create an Instagram-style feed with endless engagement metrics.

No public follower counts.

No visible like counts.

The emphasis is:

"What are my people doing right now?"

6. POST A NOW

The main action should be extremely obvious.

Primary CTA:

Post a NOW

When the user taps it:

Open camera immediately.

The user can take:

front camera photo

rear camera photo

The default experience should encourage spontaneous photos rather than polished content.

Allow optional:

caption

location context

privacy setting

After posting:

Your NOW is live.

Friends can see it.

7. NOW DROP

Create a feature called:

NOW DROP

At random times, the app sends a notification:

🔵 NOW DROP
You have 90 seconds.

The exact timing should be unpredictable.

Once triggered, users have a limited window to post.

The goal is to create anticipation and FOMO.

Show a large countdown:

01:27

When the timer reaches zero, the NOW DROP closes.

The UI should feel exciting but still minimal.

8. DOUBLE NOW

Occasionally trigger:

DOUBLE NOW
Show us what you're doing.

The user takes:

front camera

rear camera

Both are displayed together as one NOW.

Do not make this look like an Instagram collage.

Keep the composition simple and editorial.

9. WHO'S THERE?

When a user uploads a NOW containing other people, optionally use AI/computer vision to detect whether another person appears in the image.

Display:

👤 Someone's with you.

Do NOT automatically identify the person.

Friends can react or guess:

"IS THAT RAKA?"

Privacy is important.

Do not perform facial recognition or automatically reveal identities.

10. REACTION CHAIN

Replace traditional comments with lightweight reactions.

Example:

Naira:
📸 studying

Alya:
😂

Naira:
😭

Sarah:
💀

Alya:
💀💀

Reactions can respond to previous reactions, creating a small reaction chain.

Keep it visually compact.

The interaction should feel spontaneous rather than like a traditional comment section.

11. NOW QUEST

Occasionally show optional community challenges.

Examples:

TODAY'S QUEST
Find something yellow.

SHOW US
What's outside your window?

TODAY'S QUEST
Something you almost forgot today.

Users can participate by posting a NOW.

Create a simple:

Quest Gallery

showing participating NOWs.

Do not make this feel like a competitive leaderboard.

12. WORLD NOW

Create a major discovery feature.

Users can explore NOWs from random people around the world.

Example:

🇯🇵 Tokyo
12,381 NOWs

🇫🇷 Paris
4,291 NOWs

🇮🇩 Jakarta
8,923 NOWs

Users can select a location and see random public NOWs.

Important:

Do NOT turn this into an influencer discovery page.

Prioritize random people and authentic moments.

The feeling should be:

"What is happening in Tokyo right now?"

Create a simple world/city discovery interface.

13. GUESS THE PLACE

For users who enable location context:

GUESS WHERE I AM.

Friends receive several possible answers.

Example:

🏫 School
☕ Cafe
🏠 Home

Allow up to 3 guesses.

Correct guess:

+1

Do not over-gamify this.

14. TOGETHER

If two users who are friends post NOWs:

within a similar time window

and optionally within a nearby location

NOW can suggest:

🫂 You were together.

Then:

Make this a Together?

If both users agree, create a shared memory.

A Together should display both NOWs side-by-side with:

TOGETHER
20:31

Privacy must be respected.

Never automatically reveal precise location.

15. STREAKS

Use streaks carefully.

Do NOT copy Snapchat's large flame system.

Instead use subtle language:

You've been here for 17 days.

or:

17 consecutive NOWs.

If a user misses:

You missed yesterday.

No aggressive punishment.

No giant streak counters.

16. NOW AI

Create an AI-powered memory assistant.

The AI should understand the user's own NOW archive.

Example queries:

"When was the last time I saw Sarah?"

"What was I doing on my birthday?"

"Show me my happiest month."

"What did I do last summer?"

The AI should retrieve and organize the user's existing memories.

Create a simple conversational interface.

The AI should feel like a memory assistant, not a generic chatbot.

Privacy is extremely important:

personal NOWs remain private

AI should only access memories the user is authorized to access

never expose private memories to other users

17. SECRET NOW

Create:

SECRET NOW 🔒

A user can send a NOW specifically to one person.

The recipient sees:

🔐 Naira sent you a Secret NOW.

The Secret NOW can be viewed once.

After opening:

Gone.

Make the UI mysterious and minimal.

Do not make this feel like Snapchat messaging.

18. NOW EVENTS

Create community-wide events.

Example:

🌙 EVERYONE, LOOK UP.

Thousands of users can post NOWs around the same time.

Then NOW creates:

THE WORLD — 20:00

A visual collection of snapshots from different locations around the world.

Other examples:

EVERYONE, SHOW YOUR SKY.

WHAT'S OUTSIDE YOUR WINDOW?

SHOW US YOUR CITY.

Events should create collective moments without relying on influencers.

19. MEMORIES

Create a beautiful archive of the user's NOW history.

Organize by:

date

month

year

location

people

events

Together moments

Avoid making it look like a traditional photo gallery.

It should feel like a visual diary.

Example:

AUGUST 2026
31 NOWs
4 Together moments
2 Events

Allow users to replay old NOWs.

Copy:

Replay your NOWs.

20. PROFILE

Keep profiles extremely minimal.

Show:

profile photo

username

short bio

current/most recent NOW

number of NOWs

Memories

Together moments

Do NOT show:

follower obsession

following counts prominently

likes

engagement statistics

The product is about people, not popularity.

21. NOTIFICATIONS

Notifications should feel important but not overwhelming.

Examples:

🔵 NOW DROP
You have 90 seconds.

🫂 You might have been together.

🔒 You received a Secret NOW.

🎯 New NOW Quest.

🌎 Everyone is looking up.

Keep notification design minimal.

22. PRIVACY

Privacy is a core part of NOW.

Implement:

private/friends/public NOW visibility

optional location context

no automatic identity recognition

no precise location exposure

controls for who can send Secret NOWs

controls for who can see Memories

ability to delete NOWs

ability to export personal memories

World NOW should only use content users explicitly make public.

23. MVP PRIORITY

Build the application architecture so the following are functional first:

Phase 1 — Core

Authentication

User profiles

Friend system

Camera/post NOW

Friends NOW feed

Reactions

Memories

Notifications

Phase 2 — Signature features

NOW DROP

DOUBLE NOW

Reaction Chain

NOW QUEST

World NOW

Guess the Place

Together

Phase 3 — Advanced

Secret NOW

NOW Events

NOW AI

Advanced memory search

Use mock data where external APIs are not available, but structure the application so real services can be connected later.

24. UX PRINCIPLE

The entire app should follow one rule:

Less scrolling. More moments.

Do not build an infinite-content algorithmic feed.

Every screen should feel intentional.

The user should be able to understand the product within seconds.

The core loop is:

Open NOW
↓
See your people
↓
Post your NOW
↓
React
↓
Discover the WORLD
↓
Participate in EVENTS
↓
Build MEMORIES
↓
Come back tomorrow

25. TECHNICAL DIRECTION

Build this as a responsive mobile-first web application/PWA.

Use:

React

TypeScript

Tailwind CSS

modern component architecture

clean reusable components

responsive design

accessible interactions

Use realistic mock data for the prototype.

Structure the code so backend services, authentication, storage, notifications, AI, and location services can be integrated later.

Prioritize polished UI/UX over backend complexity for the first prototype.

FINAL DESIGN DIRECTION

The finished product should make someone think:

"Oh, I get it. This is where I see what my people are doing NOW."

It should feel like a combination of:

BeReal's spontaneity
+
Notion's visual simplicity
+
a personal visual diary
+
a window into the entire world

But it must ultimately feel like its own product:

NOW

See your people, right now.
